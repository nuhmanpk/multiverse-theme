# Changelog

## 0.0.1
- First release: **93 color themes in 14 groups**:
  - Core, Accessibility (color-blind-safe Clear Sight, Night Shift, Sunlight) and Focus & Workflow
  - Heroes & Villains, Anime, Cartoons, Sci-fi & Games and Retro
  - Dev Culture, Moods & Seasons and Nature, Food & Myth
  - Art & Design, Neon & Electric and Luxe & Cinematic
- **21 file icon styles**: essentials, pop, characters (Buddies, Critters, Monsters) and premium (Isometric, Clay, Holo, Sketch, Retro OS, Paper Cut).
- **325 file types** covering 1,863 extensions and 1,537 file names, and **40 folder kinds** recognized from 753 names.
- **93 kawaii mascots**, one per theme, shown in the theme picker, gallery and README.
- Commands: live-preview pickers for themes and icon styles, random, next/previous and daily universe.
- Time-of-day schedule and a status-bar indicator.
- Build-time WCAG contrast guard and a color-vision-deficiency simulation audit.
- Auto-generated, animated README art: banner, theme gallery, icon galleries and mascot grid.
